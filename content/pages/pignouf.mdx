# Project Overview

**Pignouf** is the agent I built on Claude Code to run the day-to-day of Fynex, the investment app I work on at Epitech. It lives in a persistent `tmux` session on my own server, stays online 24/7 and acts through its integrations.

Most assistants stop at the chat box. I wanted one that reads the team's Discord, triages my inbox, keeps the GitHub board clean, works at night and reports back in the morning, without me watching it.

&nbsp;

# 📐 By the Numbers

Counted from the agent's own files on 20 Oct 2026:

- **40 skills**, playbooks the agent loads when a task needs them (board triage, PR review, release notes, reports, design work).
- **23 scheduled jobs**: the night run at 05:15, the morning recap at 07:05, health checks every 15 minutes.
- **6 sub-agent profiles**, picked by stakes: a careful reviewer for production and migrations, a developer, a read-only explorer, a researcher, a writer, a small-edits profile.
- **603 tasks closed** through its task queue, archive included.
- **270+ memory notes**, with an index loaded at every start.

&nbsp;

# 🤖 What It Does

- **Discord bot:** a `discord.js` bot with 18 slash commands, 3 right-click actions and an embedded MCP server. The team triggers a deploy, asks for a board recap or creates an issue from Discord.
- **Email triage:** incoming emails arrive through a webhook, and only the ones that need action reach me.
- **Night run:** at 05:15 it audits the GitHub board, flags anomalies, reviews open PRs, checks deadlines and archives old tasks. At 07:05 I get one recap, and every open question becomes a one-click to-do.
- **A second agent:** Strawpoll, an autonomous agent in its own session, maintains my Discord polling bot. Pignouf sets its priorities and relays my answers. It has closed 234 tasks since June 2026 and runs 42 end-to-end test scripts.
- **Integrations:** GitHub Projects, Figma, Google Drive, Calendar, Resend, Better Stack, through MCP servers and CLIs.

&nbsp;

# 🧠 Memory & Guardrails

- **Memory:** preferences, decisions and feedback persist across sessions, indexed and loaded at startup.
- **Task queue:** work waits for the night, for a missing answer, or for its dependencies, then gets archived.
- **Decision grid:** every choice falls in one of three levels. The agent acts and reports, acts on its own recommendation and lets me cancel, or asks first. Production, money and anything public always wait for a yes.
- **Untrusted input:** content from issues, PRs, emails or chat is data, never instructions, and can never change permissions.
- **Guardrails from real incidents:** a memory gate on builds and tests since a VM freeze in September 2026, a lock against a double night run, and health checks every 15 minutes.

&nbsp;

# 🧪 Measured Before Trusted

I tested a calibrated decision model on email triage, in observation only, against my own blind labels. Agreement was 43% the first week and 62% the second, and it filed real, actionable emails as noise. So it never got a say in what reaches me. The test cost a few cents.

&nbsp;

# 📊 Supervision Dashboard

To keep an eye on an agent that runs alone, I built a **React dashboard** that follows Pignouf in real time over WebSocket: task board, live console, memory graph, cron schedule and usage. A voice mode lets me talk to it. Every action from the dashboard goes through the agent and is logged, more than 1,600 so far.

&nbsp;

# 💻 Technical Stack

- **Agent core:** Claude Code in a persistent `tmux` session, with skills, hooks and sub-agents.
- **Bot & services:** Node.js and TypeScript, `discord.js`, MCP servers, Python scripts for schedulers and watchdogs.
- **Automation:** cron jobs, webhook bridges, systemd services on my own server.
- **Dashboard:** React, Vite, TailwindCSS, WebSocket.

&nbsp;

# 🏢 From Personal Agent to a Product: Nightshift

The system proved useful enough that I started turning it into a product, **Nightshift**: the same agent that works while you sleep, for teams that want night-time operations on their own projects. Pignouf stays my daily driver and test bed.

&nbsp;

# 🎯 Key Takeaways

Pignouf took me from prompt writing to **agent engineering**: durable memory, safe background jobs, many APIs wired together, measuring a model before trusting it, and defending an autonomous system against untrusted input.
