# Project Overview

Fynex is an investment tracking app for **active stock investors**: people who manage their own shares and place orders every month. It **saves them time** by centralizing what is usually scattered across several apps: portfolio positions, watchlists, market data, relevant news and upcoming events (dividends, earnings, general meetings, reports). It is live at [fynexapp.com](https://fynexapp.com).

This project is a **2-year school project** developed as part of our curriculum, built by a team of three: **Augustin Bost** ([https://www.linkedin.com/in/augustin-bost/](https://www.linkedin.com/in/augustin-bost/)) and **Guillaume Blaizot** ([https://www.linkedin.com/in/guillaume-blaizot-138225262/](https://www.linkedin.com/in/guillaume-blaizot-138225262/)) on the backend/product side, and me as the **Frontend Developer** in charge of the web interface, UI integration, and overall dashboard experience (design system, components, and user flows). I also built the MCP server and the AI features described below.


My focus on the project is both **product/design** and **frontend implementation**, with a strong emphasis on:
- a consistent dark UI with high information density (without feeling cluttered),
- “3-click access” to the most important actions and signals,
- event-driven investing (what’s coming next and why it matters).

# 📈 Portfolio & Stock View

<img src="/preview/fynex-2026-portfolio.png" alt="Fynex portfolio view, from the public portfolio page of fynexapp.com" className="rounded-lg w-full" />

&nbsp;

The **portfolio view** shows every position across accounts in one place, with gains, income and how it compares with the market. Each stock then gets its own screen: a single place to understand *what’s happening*, *what changed*, and *what’s next*.

What the stock screen shows:
- **Readable charting** with timeframe switching and a clean tooltip experience.
- **Key metrics** (market cap, P/E, EPS, revenue, dividend yield, 52w range, volume) always visible.
- A dedicated **events panel** (ex: earnings) with a calendar-like display and an **“Add to calendar”** action.
- A space for **AI news summaries** and “upcoming event” context (so users don’t have to read 15 articles to understand the signal).

&nbsp;

# 🔌 MCP Server for AI Assistants

<img src="/preview/fynex-2026-mcp.png" alt="Fynex in an AI assistant, from the public MCP page of fynexapp.com" className="rounded-lg w-full" />

&nbsp;

Fynex includes a remote **MCP server**, so a user can connect an AI assistant such as Claude, ChatGPT or Cursor to their account and ask about their portfolio, upcoming dividends, sector allocation or a quote.

- **OAuth 2.1** sign-in, with a consent screen and access the user can revoke from their profile.
- **Read-only by default**: editing the portfolio tracking is an explicit opt-in.
- No tool can place an order or delete a portfolio, and every call is logged.

# 🤖 Fynex Intelligence

<img src="/preview/fynex-2026-intelligence.png" alt="A Fynex Intelligence note on a stock move, from the public page of fynexapp.com" className="rounded-lg w-full" />

&nbsp;

Fynex Intelligence is the AI layer, built on the **Claude API**. It is designed to *reduce analysis time*, not to add more charts:
- news summaries and the tone of the news on each stock,
- short company descriptions and a market outline,
- a stock analysis, and explanations of notable moves on the stocks a user follows.

Each feature has a versioned prompt and a spending cap, monitored from an admin page.

*(No financial advice: the goal is to help users organize, understand and monitor information faster.)*

&nbsp;

# 📰 Market News Newsletter

A newsletter sends subscribers a short article on a market move: the stocks involved, what changed and why it matters, without any buy or sell advice. Anyone can sign up at [fynexapp.com/newsletter](https://fynexapp.com/newsletter).

# 💻 Technical Stack

Fynex uses a modern, production-oriented stack:

- **Frontend:** React + Vite, React Router, TailwindCSS, Axios, Zod
- **Backend:** NestJS (Node.js + TypeScript), JWT auth, dotenv
- **Data:** Supabase (PostgreSQL) as the primary database, Redis for caching
- **Market data:** Twelve Data API for prices, fundamentals and company events
- **Infra / DevOps:** Docker + Docker Compose on a VPS, Nginx reverse proxy, HTTPS with Certbot, CI/CD with GitHub Actions
- **AI:** Claude API (Anthropic), MCP server with OAuth 2.1
- **API Docs:** Swagger / OpenAPI

# 🎯 Key Features

- Portfolio tracking, by hand or by importing a statement
- Watchlist with quick actions, sorting and filtering
- Stock view with charting and key metrics
- Event timeline (earnings, dividends, reports, general meetings)
- Fynex Intelligence: AI news summaries and analyses
- MCP server to use Fynex from an AI assistant
- Alerts and notifications configurable per user
